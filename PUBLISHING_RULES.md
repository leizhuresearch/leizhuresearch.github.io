# Publishing rules (my own, in addition to the template's agent guidance)

This repository is PUBLIC. Every committed file is visible to anyone,
including files that are not rendered on the site and the full git history.

## Never commit

- Unpublished results, draft manuscripts, or data.
- Anything from my research hub marked `confidential: true`.
- Names or details of collaborators or students without their permission.
- Personal contact details beyond what I have explicitly approved.
- API keys, tokens, or credentials.

## Workflow

- Drafts live in my private research hub, not in this repo.
- Do not push to `main` without my explicit approval; pushing to `main` publishes.
  Prefer a separate branch and a pull request for my review.
- Do not edit the `gh-pages` branch; it is generated automatically.

## Content

- Audience: researchers in my field, prospective students and collaborators.
- Tone: clear and factual, no hype.
- Publications come only from `_bibliography/papers.bib`.
